데이터베이스(inventory.db)를 압축(ZIP)하여 보관하고, 매일 자정에 설정된 이메일로 자동 전송합니다.

⚙️ 백업 및 메일 발송 설정

ℹ️ PythonAnywhere 무료계정 설정 안내

⚠️ PythonAnywhere 무료 계정은 포트 587/465 (SMTP)를 차단하므로 [Resend API] 방식을 사용해야 합니다.

  1. Resend 가입: https://resend.com 접속 후 무료 회원가입
  2. API Key 발급: [API Keys] 메뉴에서 키 생성 (형식: re_...)
  3. 위 폼의 전송 방식을 [Resend Web API]로 선택 후 발급받은 API Key를 입력하고 저장!

※ Resend는 매월 3,000건(하루 100건) 이메일을 평생 무료로 제공합니다.
