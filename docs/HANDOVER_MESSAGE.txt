[세한메카트로닉스 홈페이지 인수인계]

■ 홈페이지
https://www.shm21.kr

■ 코드 저장소
https://github.com/jwonrt-beep/sehan

■ 받는 분이 먼저 준비할 것
1) https://github.com 에서 무료 가입
2) GitHub 아이디(또는 가입 이메일)를 넘기는 분에게 알려주기

■ 넘기는 분이 할 일
1) 위 저장소 → Settings → Collaborators → Add people
2) 받는 분 아이디로 초대 (Write 또는 Admin)
3) 받는 분에게 “초대 수락해 주세요” 안내

■ 받는 분이 할 일
1) 이메일 또는 GitHub 알림에서 초대 수락
2) 저장소가 열리면 권한 받은 것
3) 자세한 설명은 저장소 파일 docs/HANDOVER.md

■ 전권일 때 추가
도메인 www.shm21.kr 등록 업체 계정도 함께 전달
(GitHub만 있으면 내용 수정은 가능, 주소/DNS는 도메인 계정 필요)
