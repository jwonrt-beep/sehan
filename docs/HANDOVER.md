# 세한메카트로닉스 홈페이지 인수인계

**넘기는 분**과 **받는 분**이 같이 보면 됩니다.  
어려운 말은 줄이고, **무엇을 → 어떻게**만 적었습니다.

---

## 0. 한 줄로 이해하기

| 구분 | 내용 |
|------|------|
| 홈페이지 주소 | https://www.shm21.kr |
| 코드가 있는 곳 | https://github.com/jwonrt-beep/sehan |
| 수정 반영 방식 | 코드 수정 → GitHub에 올리기(push) → **자동으로** 홈페이지 반영 |

**권한 = GitHub에서 이 저장소를 고치고 올릴 수 있는 권리**  
이게 없으면 파일을 받아도 홈페이지에는 반영할 수 없습니다.

# 1부. 넘기는 분 (지금 권한을 가진 분)

## 1-1. 상대에게 미리 받아 둘 것

상대방에게 아래를 **먼저 물어보세요.**

1. **GitHub 아이디** (또는 가입한 이메일)  
   - 아직 없으면 → 상대가 https://github.com 에서 무료 가입  
2. (전권일 때) 도메인·DNS를 받을 사람의 **이메일**

GitHub 아이디가 있어야 **초대**를 보낼 수 있습니다.

---

## 1-2. GitHub 저장소 권한 주는 방법 (필수)

### 순서

1. 브라우저에서 저장소 열기  
   → https://github.com/jwonrt-beep/sehan
2. 위쪽 메뉴 **Settings** (설정) 클릭  
   - Settings가 안 보이면: 본인 계정이 저장소 **Owner/Admin**인지 확인
3. 왼쪽 메뉴에서 **Collaborators** (또는 Collaborators and teams) 클릭  
   - GitHub 화면: **Settings → Collaborators**
4. **Add people** (사람 추가) 클릭
5. 상대의 **GitHub 아이디** 또는 **이메일** 검색 후 선택
6. 권한 선택  
   - **Write** : 수정·올리기 가능 (보통 이것)  
   - **Admin** : 설정·배포·사람 초대까지 전부 (진짜 전권)
7. **Add ○○○ to this repository** 로 초대 전송
8. 상대에게 알려주기  
   - “GitHub 메일함 또는 https://github.com/jwonrt-beep/sehan 에서 **초대를 수락**해 주세요”

### 전권으로 넘길 때 권장

- 당장: **Admin** 으로 초대  
- 나중에 완전히 넘기려면: 저장소 **Transfer** (소유권 이전)도 가능  
  - Settings → General → 맨 아래 **Danger Zone → Transfer ownership**

---

## 1-3. 도메인(www.shm21.kr) 전권 넘기는 방법

홈페이지 “주소”는 도메인입니다. GitHub만 넘기면 **사이트 내용은 관리**할 수 있고,  
**주소 자체·DNS**까지 넘기려면 도메인 등록 업체 계정도 필요합니다.

### 넘기는 분이 할 일

1. 도메인을 산 **등록 업체** 확인 (가비아, 후이즈, Cloudflare, AWS 등)
2. 그 업체 관리자 페이지 로그인
3. 아래 중 하나로 처리  
   - **관리자/부계정 추가**로 상대 이메일 초대, 또는  
   - **계정 정보·비밀번호를 안전하게 전달** (메신저보다 비밀번호 관리 도구 권장), 또는  
   - 업체에 **명의/관리권 이전** 신청
4. DNS에 GitHub Pages 연결이 되어 있는지 상대에게 보여주기  
   - 보통 `www` → GitHub Pages용 CNAME  
   - (설정이 깨지면 사이트가 안 열릴 수 있으니, 변경 전 스크린샷 저장 권장)

### 도메인만 없고 GitHub만 넘기면?

- 상대는 **내용 수정·배포**는 가능  
- **도메인 만료·DNS 변경**은 여전히 넘기는 분(또는 도메인 소유자) 담당

---

## 1-4. 넘기는 분이 상대에게 보낼 메시지 (복붙)

아래를 카톡/메일로 보내면 됩니다.

```
[세한메카트로닉스 홈페이지 인수인계]

1) 홈페이지
https://www.shm21.kr

2) 코드 저장소
https://github.com/jwonrt-beep/sehan

3) 제가 GitHub에서 초대 보냈습니다.
   → GitHub 로그인 후 초대를 수락해 주세요.
   → 수락하면 저장소를 수정하고 push 할 수 있습니다.

4) 자세한 설명
저장소 안 파일: docs/HANDOVER.md

5) 필요하시면 도메인(www.shm21.kr) 관리 계정도 별도로 전달합니다.
```

---

## 1-5. 넘기는 분 체크리스트

- [ ] 상대 GitHub 아이디 받음
- [ ] Collaborator 초대 보냄 (Write 또는 Admin)
- [ ] 상대가 초대 **수락**했는지 확인
- [ ] (전권) 도메인 계정/DNS 접근 방법 전달
- [ ] 이 문서(`docs/HANDOVER.md`) 위치 알려줌
- [ ] 연락처·사진 원본 등 필요 자료 전달

# 2부. 받는 분 (앞으로 관리할 분)

## 2-1. 받기 전에 준비할 것

| 준비물 | 설명 |
|--------|------|
| **GitHub 계정** | https://github.com 무료 가입 |
| **본인 아이디/이메일** | 넘기는 분에게 알려줘야 초대 가능 |
| (선택) Git / Cursor / VS Code | 파일 수정·올리기용 |
| (전권) 도메인 로그인 | 넘기는 분이 별도로 줌 |

**비밀번호나 주민번호 같은 건 GitHub 초대에 필요 없습니다.**  
필요한 건 **GitHub 계정**뿐입니다.

---

## 2-2. 권한 받는 방법 (초대 수락)

1. 넘기는 분이 Collaborator 초대를 보냄
2. 아래 중 하나로 수락  
   - GitHub에 가입한 **이메일** 확인 → Accept invitation  
   - 또는 https://github.com/jwonrt-beep/sehan 접속 시 뜨는 **초대 배너**에서 Accept  
   - 또는 https://github.com/notifications 에서 초대 알림
3. 수락 후 저장소가 보이면 성공  
4. 테스트: 작은 수정 또는 README에 한 줄 추가 → commit → push  
5. 1~3분 뒤 https://www.shm21.kr 반영 여부 확인

### 초대가 안 보이면

- 넘기는 분에게 “초대를 다시 보내 달라” 요청
- GitHub에 **초대한 이메일과 같은 계정**으로 로그인했는지 확인
- 스팸함 확인

---

## 2-3. 받는 분이 할 수 있게 되는 일

권한을 받으면:

- 홈페이지 글·사진 수정
- GitHub에 올려서 실제 사이트에 반영
- (Admin이면) 배포 설정·다른 사람 초대도 가능

도메인까지 받으면:

- `www.shm21.kr` 주소·DNS 관리
- 도메인 연장·이전

---

## 2-4. 받는 분 체크리스트

- [ ] GitHub 가입 완료
- [ ] 초대 수락 완료
- [ ] 저장소 열림 확인
- [ ] push 테스트 성공
- [ ] www.shm21.kr 접속 확인
- [ ] (전권) 도메인 로그인 확인

# 3부. 사이트 관리 방법 (받는 분용)

## 3-1. 수정 → 반영 흐름

```
1. 파일 수정 (또는 이미지 추가)
2. git add / commit / push  (main 브랜치)
3. GitHub → Actions 에서 Deploy 성공 확인
4. 홈페이지 새로고침 (1~3분 소요될 수 있음)
```

로컬 폴더에만 두고 push 안 하면 **사이트에는 안 나옵니다.**

---

## 3-2. 자주 고치는 파일

| 목적 | 파일 |
|------|------|
| 메인 | `index.html` |
| 제품·설비 사진 | `products.html` + `assets/images/products/panasonic/` |
| 주소·전화 | `locations.html`, 각 페이지 푸터 |
| 문의 | `contact.html` |
| 회사소개 | `company.html` |
| 인증 | `certifications.html` |
| 구축사례 | `cases.html` |

---

## 3-3. 제품·갤러리 사진

**보는 곳:** 메뉴 「제품 및 시스템」 → 아래로 스크롤 → 「실제 설비 및 적용 이미지」

**넣는 곳:** `assets/images/products/panasonic/`  
파일명은 README에 적힌 그대로 (`facility-01.jpg` …).  
이름 바꾸면 안 나옵니다.

---

## 3-4. 아직 비어 있을 수 있는 것

- 메인 히어로: `images/hero-robot.jpg`
- 구축사례·인증서·사업장 사진 (텍스트/빈 칸일 수 있음)
