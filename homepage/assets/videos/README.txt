====================================================================
세한메카트로닉스 홈페이지 — 전시회 및 로봇 시연 동영상 업로드 안내
====================================================================

새로운 동영상이 생길 때마다 홈페이지에 올리는 방법은 아래 3가지 중 편한 방법을 쓰시면 됩니다.
또한 코딩 없이 화면에서 편하게 영상을 추가하시려면 홈페이지 폴더 안의
[ video-manager.html ] 파일을 더블클릭하여 실행해 보세요!

--------------------------------------------------------------------
방법 1. 가장 추천! 유튜브(YouTube) 무료·무제한 공간 활용 (용량/개수 무제한)
--------------------------------------------------------------------
- GitHub는 파일 1개당 100MB, 전체 저장소 1GB 제한이 있습니다.
- 반면 유튜브에 영상을 올리면 4K 고화질·장시간 영상도 무료로 무제한 올릴 수 있습니다.
- 유튜브에 올릴 때 공개 상태를 [일부 공개(Unlisted)]로 설정하면 유튜브 검색에는
  노출되지 않고, 오직 세한메카트로닉스 홈페이지 방문자만 볼 수 있습니다.
- 업로드 후 유튜브 링크(예: https://youtu.be/xxxx)를 복사하여
  `video-manager.html` 또는 `js/videos-data.js`의 `videoUrl`에 붙여넣으시면 끝납니다!
  (썸네일 사진도 유튜브에서 자동으로 가져옵니다.)

--------------------------------------------------------------------
방법 2. 이 폴더(assets/videos/)에 MP4 파일 직접 넣기 (소용량 영상용)
--------------------------------------------------------------------
- 파일 크기가 50MB 이하인 짧은 MP4 영상은 이 폴더(`assets/videos/`)에 직접 넣으셔도 됩니다.
- 현재 기본 연결된 파일 이름:
  * exhibition-01.mp4 (파나소닉 용접 로봇 시스템 전시회 라이브 시연)
  * exhibition-02.mp4 (멀티 로봇 동시 용접 및 포지셔너 연동 시스템)
  * exhibition-03.mp4 (자동 이송 · 적재 및 공정 자동화 시연)
  * exhibition-04.mp4 (도입 전 3D 로봇 동작 시뮬레이션 검증)
- 위 이름으로 이 폴더에 MP4 파일을 넣거나, 새 파일 이름을 `js/videos-data.js`에 추가한 뒤
  GitHub에 push 하시면 홈페이지에서 바로 재생됩니다.

--------------------------------------------------------------------
방법 3. GitHub Releases 또는 구글 드라이브 무료 공간 활용 (파일당 최대 2GB)
--------------------------------------------------------------------
- 유튜브 로고 없이 자체 비디오 플레이어로 대용량(50MB ~ 2GB) MP4 원본을 재생하고 싶다면:
  1) GitHub 저장소(https://github.com/jwonrt-beep/sehan/releases)에서
     [Create a new release] → 동영상 MP4 파일을 드래그 앤 드롭하여 업로드 후
     생성된 다운로드 주소(https://github.com/.../파일명.mp4)를 `videoUrl`에 넣거나,
  2) 구글 드라이브(무료 15GB)에 영상을 올리고 [링크가 있는 모든 사용자에게 공개] 후
     공유 링크(https://drive.google.com/file/d/.../view)를 `videoUrl`에 넣으시면 됩니다.
